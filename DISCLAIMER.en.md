## Credentials and data

Desktop import is explicitly initiated by the user and stores the relay's own credential copy without modifying TRAE client login files. File permissions restrict access to the plugin data directory, but account copies and configuration are not an encrypted vault and do not protect against programs or users with sufficient system privileges. Do not share this directory, logs, API keys or screenshots containing real account information. Retained data requires manual cleanup after uninstalling.
